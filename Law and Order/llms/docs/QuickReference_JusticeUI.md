# Justice UI - Quick Reference

## Opening the Window
- Click "Justice" button on hotbar
- Or press `J` key

## Tabs
- **Active Criminals**: Living criminals not in prison
- **Imprisoned**: Criminals currently imprisoned
- **Historical**: Deceased criminals

## Features

### Search
Type in search box to filter by name

### Criminal List
Click any criminal to view details:
- Name and portrait
- Crime count
- Imprisonment status

### Detail Panel
Shows for selected criminal:
- Full name
- Current status
- Trial status
- Complete crime list with:
  - Crime type
  - Victim
  - Damage dealt
  - Days ago

### Actions

**Schedule Hearing**
- Requires valid courtroom
- Shows error if no courtroom exists

**Release** (prisoners only)
- Converts prisoner to guest

**Pardon**
- Removes all crimes
- Deletes criminal record

**View Info**
- Opens character info card

## Courtroom Requirements
Minimum valid courtroom needs:
- 10+ cells of space
- At least one chair/throne/stool
- Indoor room

## Quick Tips
- Search filters the current tab
- Most impressive room is auto-selected for hearings
- Pardon is permanent and cannot be undone
- Released prisoners become guests (not freed)

## Hotkeys
- `J` - Open/close justice window
- `Esc` - Close window

## Integration
- Automatically shows all pawns with criminal records
- Updates in real-time as crimes are recorded
- Works with crime tracking system
